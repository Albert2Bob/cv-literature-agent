# 深度学习训练技巧与实验调优

## 1. 优化器选择

> 关键词：SGD、Momentum、Adam、AdamW、LAMB

| 优化器 | 更新方式 | 优点 | 缺点 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| SGD | $\theta \leftarrow \theta - \eta g$ | 泛化好，最终精度常最高 | 收敛慢，对学习率敏感 | CNN 分类/检测，需长训练 |
| SGD + Momentum | 累积历史梯度 | 抑制震荡，加速收敛 | 需调 momentum | 视觉任务默认选择 |
| Adam | 一阶/二阶矩自适应 | 收敛快，几乎不用调 | 权重衰减实现有误，泛化略差 | Transformer、小数据集快速实验 |
| AdamW | Adam + 解耦权重衰减 | 正则化正确，泛化更好 | — | **Transformer / ViT 的默认优化器** |
| LAMB | 逐层自适应 + 全局范数裁剪 | 支持超大 batch | 实现复杂 | 大 batch 分布式训练 |

**关键点：Adam 中的 L2 正则与权重衰减不等价。** Adam 的 L2 会把正则项加进梯度并被二阶矩归一化，导致大梯度参数的衰减被削弱。AdamW 把权重衰减从梯度中解耦出来直接作用于参数，才是正确的实现。

## 2. 学习率调度

> 关键词：warmup、cosine decay、step decay、OneCycle

- **Warmup**：前若干 step（500~2000）把学习率从接近 0 线性升到目标值。Transformer 没有 warmup 时极易发散，因为早期注意力权重随机、梯度方差大。
- **Cosine 退火**：$\eta_t = \eta_{min} + \frac{1}{2}(\eta_{max}-\eta_{min})(1+\cos(\frac{t}{T}\pi))$，平滑下降，是当前主流。
- **Step decay**：在固定 epoch（如 30/60/90）乘以 0.1。ResNet 经典配方，简单有效。
- **OneCycle**：先升后降，配合大学习率，能显著缩短训练周期（super-convergence）。
- **Linear scaling rule**：batch size 扩大 $k$ 倍，学习率也扩大约 $k$ 倍；配合 warmup 更稳。

**学习率是最重要的超参**。经验起点：CNN + SGD 用 0.1（batch 256）；Transformer + AdamW 用 1e-4 ~ 3e-4（微调用 1e-5 ~ 5e-5）。

## 3. 数据增强

> 关键词：flip、crop、color jitter、Mixup、CutMix、Mosaic、RandAugment

**基础增强**（分类、检测、分割通用）：随机水平翻转、随机裁剪/缩放、颜色抖动（亮度/对比度/饱和度/色调）、旋转、高斯噪声。

**增强必须与任务语义一致**：
- 水平翻转对自然图像安全，但**文字识别、交通标志、左右手区分**的任务会破坏语义。
- 几何变换必须对图像与标注（框、掩码、关键点）施加同一参数。
- 检测任务裁剪后要重新过滤并裁剪标注框，丢弃面积过小的框。

**强增强策略**：

| 方法 | 做法 | 效果 |
| :--- | :--- | :--- |
| Mixup | 两张图线性混合，标签也线性混合 | 提升校准性与鲁棒性，训练变慢 |
| CutMix | 把一张图的区域贴到另一张，标签按面积加权 | 比 Mixup 更强，定位任务友好 |
| Mosaic（YOLO） | 四张图拼成一张 | 大幅提升小目标与上下文多样性 |
| RandAugment | 从增强池随机选 N 个操作 + 统一强度 | 免去逐操作调参 |
| Copy-Paste | 实例复制粘贴到其他图 | 实例分割/检测提升显著 |

**注意**：强增强在**小数据集**上收益最大，但在大数据集或已充分预训练时可能无收益甚至负收益；测试时增强（TTA）与训练增强不应盲目叠加。

## 4. 正则化

> 关键词：weight decay、Dropout、DropPath、Label Smoothing、EMA

- **权重衰减**：L2 正则，抑制大权重。Transformer 通常 0.05，CNN 通常 1e-4~5e-4。
- **Dropout**：随机置零神经元。全连接层常用 0.5，卷积层少用（会破坏空间结构）。
- **DropPath / Stochastic Depth**：随机丢弃整个残差分支，训练深层网络（ViT、Swin）必备。
- **Label Smoothing**：把 one-hot 标签软化，缓解过自信，改善校准性；检测中常用 $\epsilon=0.1$ 的变体。
- **EMA（指数滑动平均）**：对模型参数做滑动平均，推理时用 EMA 权重，通常免费涨点。分割与自监督任务几乎标配。
- **早停**：按验证指标不再提升的轮数停止，最简单有效的防过拟合手段。

## 5. 显存优化与加速

> 关键词：AMP、gradient accumulation、checkpointing、channels_last、梯度累积

| 手段 | 原理 | 代价 |
| :--- | :--- | :--- |
| 混合精度（AMP） | FP16/BF16 前向反向，FP32 主权重 | 需 loss scaling，个别算子不稳定 |
| 梯度累积 | 多个 mini-batch 累加梯度后再更新 | 等效大 batch，但 BN 统计仍基于小 batch |
| 梯度检查点 | 不保存中间激活，反向时重算 | 显存降 50%+，速度降 20~30% |
| channels_last | NHWC 内存布局，配合 Tensor Core | 需模型与算子支持 |
| 分布式数据并行（DDP） | 多卡梯度 all-reduce | 需处理 BN 与学习率缩放 |
| ZeRO / FSDP | 分片优化器状态与参数 | 配置复杂 |

**batch size 过小的后果**：BN 统计量不准（改用 GroupNorm 或冻结 BN）、梯度噪声大（需降学习率或用梯度累积）。**batch size = 8 对 $512\times512$ 输入偏小但可用**，能上 16 更稳。

## 6. 迁移学习与微调策略

> 关键词：fine-tune、freeze、layer-wise lr decay、差分学习率

- **数据量小 + 领域接近**：只训练分类头，冻结 backbone。
- **数据量小 + 领域差异大**：冻结浅层，微调深层；或整体微调但用极小学习率（1e-5）。
- **数据量大**：整体微调，可用正常学习率 + 差分学习率（浅层小、深层大）。
- **检测/分割微调**：backbone 用 0.1× 学习率，新初始化的头用 1×；小 batch 时冻结 BN。
- **注意预训练权重的域差异**：ImageNet 自然图像权重迁移到遥感、医学、红外图像时收益会打折，但仍普遍优于随机初始化。

## 7. 消融实验设计规范

> 关键词：ablation、baseline、控制变量、显著性

**好的消融实验**：

1. **单一变量**：每次只改一个组件，明确"加什么涨多少点"。
2. **基线可复现**：baseline 必须是自己跑出来的，且与公开结果对齐；若对齐不上，先解释差距来源。
3. **训练预算一致**：同一 epoch 数、同一增强、同一分辨率。用短训练对比长训练方法是不公平的。
4. **多次运行取均值**：随机种子会影响 0.3~1.0 个点，单次结果不足以支撑「提升显著」的结论。至少 3 个种子并报告标准差。
5. **报告完整指标**：不能只报最好的那个指标；检测报 mAP50 与 mAP50-95，分割报 mIoU 与 Dice。
6. **复杂度对照**：参数量、FLOPs、推理延迟一并给出，否则「涨点」可能只是模型变大。

**常见审稿质疑**：只在小数据集验证、缺少与最新方法的对比、未报告失败案例、超参针对测试集调整（test set leakage）。

## 8. 训练不收敛 / 掉点的排查清单

> 关键词：debug、loss nan、不收敛、掉点

1. **先过拟合一个小样本**：拿 10~50 张图训练，能否把 loss 打到接近 0？不能则说明代码有 bug（标签、损失、梯度、数据管道）。
2. **检查标签管道**：打印若干样本的图像与标注可视化，确认框/掩码与图像对齐。这是最高频的 bug 来源。
3. **检查 loss 量级**：分类 loss 应从 $\ln(C)$ 附近开始下降；若一开始就是 0 或 NaN，八成是标签或数值问题。
4. **NaN / Inf**：降学习率、加梯度裁剪（clip_grad_norm_ 1.0~5.0）、检查除零与 log(0)、AMP 下检查 loss scale。
5. **梯度检查**：打印各层梯度范数，若某层恒为 0 说明该分支未被训练；若爆炸则需要裁剪与更好的初始化。
6. **微调掉点**：学习率过大、BN 统计失真、数据增强过强、类别数/标签映射不匹配。
7. **验证集指标波动大**：batch 太小、验证集太小、未用 EMA、学习率调度末尾抖动。
8. **固定随机种子**：`torch.manual_seed`、`numpy.random.seed`、`random.seed`、`cudnn.deterministic=True`，让对比实验可复现。
