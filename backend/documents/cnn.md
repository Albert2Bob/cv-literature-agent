# 卷积神经网络（CNN）：从卷积核到经典骨干

## 1. 卷积与感受野（Receptive Field）

> 关键词：convolution、kernel size、stride、padding、receptive field

卷积层用一组可学习的卷积核（kernel）在输入特征图上滑动，每个位置做逐元素相乘再求和，得到一个输出值。参数量只与卷积核大小和通道数有关，与图像尺寸无关——这是 CNN 相比全连接层的核心优势。

**输出尺寸公式**（输入 $W$、卷积核 $k$、步长 $s$、填充 $p$、空洞率 $d$）：

$$W_{out} = \left\lfloor \frac{W + 2p - d(k-1) - 1}{s} \right\rfloor + 1$$

**感受野**指输出特征图上一个像素对应到原始输入图像的区域大小。随着层数加深，感受野逐层扩大：

$$R_n = R_{n-1} + (k_n - 1)\prod_{i=1}^{n-1} s_i$$

其中 $R_0 = 1$。工程含义：感受野必须覆盖目标物体的尺度，才能让网络"看全"目标。如果目标的实际尺寸大于网络最大感受野，检测/分割性能会明显下降。常用手段：堆叠 $3\times3$ 卷积、使用空洞卷积（dilated convolution）、加入金字塔结构（FPN、ASPP、SPP）。

**两个 $3\times3$ 卷积等价于一个 $5\times5$ 感受野**，但参数量更少（$2\times9=18$ vs $25$）且多了一次非线性。这是 VGG 的核心设计动机。

## 2. 池化与下采样

> 关键词：max pooling、average pooling、stride、下采样

池化层不带参数，作用是降维、扩大感受野、提供一定的平移不变性。最大池化（max pooling）保留最显著响应，在分类任务中更常用；平均池化（average pooling）保留整体统计信息。

**替代方案：** 用 stride=2 的卷积代替池化（可学习下采样），在检测与分割任务中更常见，因为它不丢失信息且能参与训练。ResNet 的 stem 与下采样捷径（$1\times1$ 卷积 stride 2）就属于这类做法。

## 3. 经典骨干网络演进

> 关键词：AlexNet、VGG、GoogLeNet、ResNet、DenseNet、EfficientNet

| 网络 | 年份 | 核心贡献 | 关键设计 | 局限 |
| :--- | :--- | :--- | :--- | :--- |
| AlexNet | 2012 | 深度学习在 ImageNet 上首次大幅超越传统方法 | ReLU、Dropout、数据增强、双 GPU 训练 | 参数量集中在全连接层 |
| VGG | 2014 | 证明深度的重要性 | 全部使用 $3\times3$ 卷积堆叠，结构规整 | 参数量大（138M），计算量高 |
| GoogLeNet | 2014 | 多尺度并行 + 计算效率 | Inception 模块、$1\times1$ 卷积降维、全局平均池化 | 结构复杂，工程实现繁琐 |
| ResNet | 2015 | 残差连接解决深层退化 | 恒等映射捷径 $y = F(x) + x$、BN | 参数量随深度线性增长 |
| DenseNet | 2017 | 特征复用 | 每层与前面所有层密集连接，通道拼接 | 显存占用高 |
| EfficientNet | 2019 | 复合缩放 | 用 NAS 搜索基线后按 $\phi$ 同时缩放深度/宽度/分辨率 | 训练成本高，推理对硬件不友好 |

### 3.1 ResNet 与残差学习

深层网络退化（degradation）不是过拟合也不是梯度消失导致的，而是优化困难。残差块让网络只需学习残差映射 $F(x) = H(x) - x$，恒等映射通过捷径直接连通，梯度可以无衰减地回传。

**瓶颈结构（bottleneck）**：$1\times1$ 降维 → $3\times3$ 卷积 → $1\times1$ 升维，用于 ResNet-50/101/152，在保持表达能力的同时压缩计算量。ResNet-50 的 stage 输出通道依次为 256、512、1024、2048，最后特征图大小为 $7\times7$，因此 backbone 输出张量为 $2048\times7\times7$。

### 3.2 DenseNet

第 $l$ 层的输入是前面所有层输出的拼接：$x_l = H_l([x_0, x_1, \dots, x_{l-1}])$。优势是梯度直达、特征复用、参数量少；代价是显存随深度平方增长，因为拼接产生的中间激活都要保存。

## 4. 归一化层

> 关键词：BatchNorm、LayerNorm、GroupNorm、归一化

| 归一化 | 统计维度 | 适用场景 | 说明 |
| :--- | :--- | :--- | :--- |
| BatchNorm | 跨样本、同通道 | 大 batch 的 CNN 分类/检测 | batch 过小时统计不准，性能骤降 |
| LayerNorm | 单样本内所有通道 | Transformer、NLP、ViT | 与 batch 无关，训练稳定 |
| InstanceNorm | 单样本单通道 | 风格迁移、图像生成 | 抹掉内容相关的对比度 |
| GroupNorm | 单样本内分组通道 | 小 batch 的检测/分割 | 介于 LN 与 IN 之间，检测任务常用 |

**检测与分割任务中 batch 通常很小（1~4）**，因此常把 BatchNorm 换成 GroupNorm 或冻结 BN 的统计量。

## 5. 常见工程问题排查

> 关键词：过拟合、梯度消失、训练不收敛、BN 冻结

- **训练 loss 不下降**：学习率过大、标签错位、数据未归一化、损失函数与任务不匹配。
- **训练 loss 下降但验证不降**：过拟合。手段：数据增强、权重衰减、Dropout、早停、减小模型。
- **深层网络不收敛**：加入 BN/LN、使用残差连接、改用合适的初始化（He 初始化适合 ReLU）。
- **迁移学习微调检测/分割模型时指标掉点**：小 batch 下 BN 统计量失真，应冻结 BN 或换 GroupNorm。
- **显存不足**：混合精度（AMP）、梯度累积、梯度检查点（gradient checkpointing）、减小输入分辨率。
